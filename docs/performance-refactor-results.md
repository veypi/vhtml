# R0–R3 实施与验证

2026-09-16。完成 [重构方案](./performance-refactor-plan.md) 的第一轮核心部分，版本号维持 0.11.0，生产文件 `dist/vhtml.min.js` 已重建。R4 通用虚拟列表工具、R5 条件性布局调度不在本轮交付中。

## 实现

- **R0**：以实施前工作区 `bd1c9bb` 的 src/dist/test/scripts 为基线快照；旧测试 232 项全通过。新增别名、循环引用、独立 root、列表身份和托管任务回归。浏览器同时验证源码及生产包。
- **R1**：`targetMeta: WeakMap` 保存普通 raw 的 canonical proxy、身份和共享通知；`proxyMeta` 保存独立 scope root。读取嵌套数据只查弱缓存，不回写 raw。`SetDataRoot` 使旧继承依赖失效；旧式 `Wrap(local)` 再设 root 会显式转换该包装并退出 canonical 缓存，避免 raw 留住父级。
- **R2**：比较上轮条目数量、迭代 key、顺序及实际值，相同则跳过逐行调和。新 raw 仍是新实体；函数源 raw 仍按位置合并。仅真正包装的对象可作为身份键。销毁清空顺序快照与行缓存。
- **R3**：scope 增加 rAF 注册/取消；timeout/interval/rAF 用可清空的任务记录持有回调。自然完成前移出 pending；取消、dispose 后释放回调，即使浏览器或外部仍持有任务包装也不会继续执行业务代码。

万行浏览器验证额外发现原 `GenUniqueID` 的时间戳与短随机串可能碰撞，已加入单运行时递增序号。测试固定时钟和随机值，验证 10,000 个新 raw 的身份互异。没有引入业务主键匹配。

## 确定性结果

同一浏览器、相同测试页：两个视图各 1,000 行，每个视图持有独立数组，数组成员是相同业务 raw。比较重新提交同一批 raw 的新数组，而非预先保存 proxy 的数组。

| 操作 | R0 快照 | R0–R3 |
| --- | ---: | ---: |
| 相同列表新建 / 取消 watcher | 2,000 / 2,000 | 0 / 0 |
| 每个视图前插 1 行，新建 / 取消 watcher | 2,002 / 2,000 | 2 / 0 |
| 相同列表文本写入 | 2,000 | 0 |
| 旧行身份、焦点、选区 | 丢失 | 保留 |
| 跨视图同一对象的字段通知 | 不同步 | 同步 |

源码与生产包均通过 1,000 行 × 1/2/4 视图、10,000 行 × 1 视图检查：

- 相同列表所有旧行严格相等，新建/移动/销毁行均为 0。
- 每个视图前插 1 行只新建 1 行，旧行不移动、不销毁。索引插值发生变化时仍有必要的文本更新。
- 逆序后每个节点仍为原节点；删除前插行仅销毁该行。
- 带局部输入状态的子组件前插后保留节点、焦点、选区和输入内容。累计 mount=2，销毁前 dispose=0，最终 dispose=2。
- 每轮销毁后 liveHandles、dependencyEdges、受托管任务数相对预热基线的增量均为 0。

等价列表仍需 O(n) 收集和比较，新数组仍需一个数组代理；本轮消除的是重复行代理/绑定/组件创建与无效调和，不承诺所有列表操作 O(1)。

## aic 回归

保留 aic 已验证的投影代理缓存和虚拟列表实现。本轮只给独立测试页增加框架模块选择参数，没有增加产品功能。

生产包场景：

| 数据规模与视图数 | 挂载行 | 子树节点（含文本/注释） |
| --- | ---: | ---: |
| 1,000 条 × 1 | 16 | 1,160 |
| 10,000 条 × 1 | 16 | 1,160 |
| 1,000 条 × 2 | 32 | 2,320 |
| 1,000 条 × 4 | 64 | 4,640 |

首次分页从服务端 20 条开始、后续每页 50 条，分页延迟分别 120ms、500ms，各向上滚动 120 步；预取会在初始稳定期提前取下一页。两组最大锚点偏差均为 **0.15625px**，原可见行重建 0，滚动钳制 0，错误 0。流式更新时阅读锚点偏差 0，隐藏期间 DOM 稳定，恢复后内容同步。

20 次打开/销毁后，liveHandles 1→1、dependencyEdges 1→1；records/messages/views、残留节点均为 0。上述 DOM 数是 aic 测试消息子树的规模，不是整个应用的全页面节点数。

用户提供的 `localhost:4002/a/coder` 实际会话在独立测试页整页刷新后也完成 120 步首次向上滚动：最大偏差 **0.234375px**，原行重建 0，滚动钳制 0，框架错误 0，销毁待处理队列 0。

## 验证入口

```sh
npm test
node --expose-gc scripts/check-reactive-gc.mjs
npm run build
```

- 框架测试：247 项；覆盖原有路由缓存、slot、props、v-if、描述符等契约。
- aic 既有单元测试：261 项。
- GC 独立进程：160 个弱引用目标全部回收，同时故意保留 canceled handle、业务 raw、本已销毁 scope 和宿主任务回调。包括 canonical 循环对象、独立 root、旧式 root 转换和任务捕获的数据。
- scope 测试：自然完成 1,000 次 timeout 与 1,000 次 rAF 后 pending=0；取消后强行调用旧包装不执行业务回调；单个 cleanup 抛错不阻断后续释放。
- `test/browser/refactor.html`：默认源码；`?module=../../dist/vhtml.min.js` 验证生产包。调用 `runRefactorProbe(1000, 2)`、`runRefactorProbe(10000, 1)`、`runChildIdentityProbe()`。子组件 fixture 使用 `/vhtml/test/browser/` 路径，静态服务器需把仓库挂在 `/vhtml`。
- aic `scripts/perf/browser.html?module=/vhtml/dist/vhtml.min.js`：`runPagedScrollProbe(120, 120/500)`、`runListProbe`、`runInteractionProbe`、`runCycles`。

没有取得强制 GC 后的浏览器总堆对照，不据此宣称 JS 总堆降低到固定 MB。弱引用回收由独立 GC 实验证明；浏览器验证依赖工作量、身份、锚点和生命周期计数。加载新框架需要整页刷新。
